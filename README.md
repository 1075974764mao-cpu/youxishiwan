# 断讯 · 文泽序章

写实丧尸生存文字冒险的可玩序章 Demo（中文 UI）。

## 本地运行

```bash
cd wenze-prologue
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。

生产预览：

```bash
npm run build && npm run preview
```

## 内容说明

- 虚构地名：江北省 / 文泽（对应现实映射仅作创作设定，文中不出现真实省名城市名，除「中国」语境外）
- 含血腥、死亡结局与惊吓音效；标题页有内容警告
- 素材来源与许可证见 `public/licenses/ATTRIBUTION.md`

## 技术

Vite + 原生 JS 静态站点，适合后续用 Cursor `publish-app` 发布为可分享网页链接。
